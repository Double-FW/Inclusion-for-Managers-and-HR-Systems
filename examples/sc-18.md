# A missing upstream source

**Synthetic case:** SC-18 · **Evaluation status:** Not run with users or an assistant.

## Situation

An assistant is asked for a detailed rule from an unavailable Double FW repository.

## Example response

State that the source was not retrieved, use verified applicable guidance and record the dependency gap.

## Why this fits the guidance

The response aims for this outcome: Commitments result in funded action and honest public claims. It assigns the relevant owner and leaves any rights-sensitive decision with authorised people. Interim access should continue while outstanding work is resolved.

## Boundary

Do not invent source contents, assume privacy status or claim the collection was fully audited.

## Verification and unresolved work

Resolve corrected source/access before asserting its requirements. The action owner should agree a next update, an accessible review route and how unresolved work will be tracked. No real outcome, legal approval or user satisfaction result is claimed by this illustration.
