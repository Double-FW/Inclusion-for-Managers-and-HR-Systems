# Knowledge tables and illustrative data

All data in this folder is expressed as Markdown tables. No employee dataset is included.

| Resource | What it contains | How to use it |
| --- | --- | --- |
| [Barrier catalogue](barrier-catalogue.md) | Forty contextual barrier patterns, possible responses and intended outcomes | Find a starting hypothesis and discuss the actual task and person |
| [Outcome measures](outcome-measures.md) | Fourteen measure definitions with interpretation and privacy limits | Choose proportionate evidence for a real improvement decision |
| [Synthetic task observations](synthetic-task-observations.md) | Invented before/after numbers, workload arithmetic and conflicting outcomes | Practise interpretation without claiming a real result |
| [Topic and outcome index](topic-and-outcome-index.md) | Thirty-two stable guidance references and outcomes | Navigate to the explanation, source and boundary |

The catalogue and index organise ideas; they are not prevalence data. Numerical examples are synthetic; measures are options rather than universal thresholds. Avoid using any table to diagnose, profile or rank employees.
